# 10 — ศูนย์พิมพ์เอกสารและดาวน์โหลด PDF (Official Document & Print Center)

> **กลุ่มผู้ใช้:** Staff / IT Admin | **เวลาอ่าน:** ~6 นาที

---

## ภาพรวมของระบบงานเอกสารใน ClaimIT

ClaimIT มีระบบงานเอกสารที่ครอบคลุมทั้งการออกเอกสารทางการส่งต่อศูนย์บริการภายนอก และการออกเอกสารควบคุมภายในโรงพยาบาล แบ่งออกเป็น 3 ระบบหลัก:
1. **PDF Report ระดับรายครุภัณฑ์ (Single-Asset Report):** สร้างจากเซิร์ฟเวอร์สำหรับครุภัณฑ์แต่ละชิ้น
2. **PDF Report ระดับใบส่งเคลมรวม (Multi-Asset Claim Report):** สร้างจากเซิร์ฟเวอร์สำหรับใบเคลมรวม 1–5 ชิ้น
3. **Official Document & Print Center (Template Center):** ศูนย์รวมแบบฟอร์ม 2 รูปแบบทางการมาตรฐานโรงพยาบาลพญาไท 3 (ใบตรวจเช็คอุปกรณ์เสีย และ ใบนําทรัพย์สินออก PT3-FM-SEC-1012) พร้อมระบบ Live Quick-Edit และการจำลองกระดาษ A4

---

## ส่วนที่ 1: รายงาน PDF ระดับรายครุภัณฑ์ (Single-Asset PDF)

### วิธีการเรียกดู/ดาวน์โหลด:
- **จากตาราง Inventory:** คลิกปุ่ม `[📄 PDF]` ที่คอลัมน์ขวาสุดของแต่ละแถว (ดาวน์โหลดได้ทันทีใน 1 คลิก)
- **จากแผง Action Board:** เมื่อสแกนครุภัณฑ์แล้ว คลิกปุ่ม `[ดาวน์โหลด PDF]`
- **ผ่าน API โดยตรง:** `GET /api/assets/:tag/pdf`

### โครงสร้างเอกสาร PDF:
1. **หัวกระดาษทางการ:** โลโก้โรงพยาบาล วัน-เวลาที่พิมพ์ และหมายเลขเครื่อง
2. **ข้อมูลครุภัณฑ์อย่างละเอียด (Asset Specifications):** รหัส, ชื่ออุปกรณ์, หมวดหมู่, แบรนด์/รุ่น, S/N, จุดติดตั้ง, มูลค่าจัดซื้อ, ระยะเวลารับประกัน และสถานะปัจจุบัน
3. **บันทึกการตรวจสอบข้อมูล PDPA (PDPA Storage Security Audit):** ยืนยันว่าต้องล้างข้อมูลหรือไม่, สถานะการล้างข้อมูล, ชื่อช่างผู้ดำเนินการ, และวัน-เวลาที่ทำความสะอาดข้อมูล
4. **ข้อมูลประวัติการส่งเคลม (Vendor RMA Service Details):** แสดงศูนย์บริการ, หมายเลข RMA, วันส่ง, วันคาดว่าจะได้รับคืน, ผลการซ่อมแซม, และค่าใช้จ่าย

---

## ส่วนที่ 2: รายงาน PDF ระดับใบส่งเคลมรวม (Multi-Asset Claim Report)

### วิธีการเรียกดู/ดาวน์โหลด:
- **จากตาราง Claims Board:** คลิกปุ่ม `[📄 PDF]` ของใบเคลมนั้น
- **จากหน้าต่าง Claim Details Modal:** คลิกปุ่ม `[📄 ดาวน์โหลด PDF ใบเคลม]`
- **ผ่าน API โดยตรง:** `GET /api/claims/:id/pdf`

### โครงสร้างเอกสาร PDF:
1. **หัวเอกสาร:** `ClaimIT — Multi-Asset Warranty & RMA Report`
2. **ข้อมูลสรุปงานเคลม:** หมายเลขใบเคลม (เช่น `CLM-2026-001`), ชื่อศูนย์บริการ, หมายเลข RMA Vendor, สถานะ, ผู้สร้างเอกสาร, และ **คะแนนความคุ้มค่า (Viability Score)**
3. **ตารางรายการครุภัณฑ์ (1 ถึง 5 รายการ):**
   - รหัสครุภัณฑ์, ชื่ออุปกรณ์, หมวดหมู่, ยี่ห้อ/รุ่น, S/N
   - วันสิ้นสุดการรับประกัน
   - สถานะความปลอดภัยข้อมูล (PDPA Sanitization: PASS / N/A)
4. **คำประกาศมาตรฐานความปลอดภัย (PDPA & ISO/IEC 27001 Compliance Statement)**

## ส่วนที่ 3: ศูนย์พิมพ์เอกสารทางการ (Official Document & Print Center)

เปิดใช้งานได้จาก:
- **Staff Portal:** คลิกปุ่ม `[พิมพ์แบบฟอร์มส่งซ่อม/เคลม]`
- **IT Portal:** คลิกปุ่ม `[แบบฟอร์มพิมพ์ทางการ (Official Forms)]`

### 2 แบบฟอร์มทางการหลักของโรงพยาบาลพญาไท 3:

| รหัส / ตัวเลือก | ชื่อแบบฟอร์ม | การนำไปใช้งาน |
|---|---|---|
| `inspection` | **ใบตรวจเช็คอุปกรณ์ เสีย (Hospital Inspection Form)** | แบบฟอร์มตรวจเช็คอาการเสีย ผู้ตรวจ ผู้ดำเนินการ และบันทึกส่งเคลม/ซ่อม |
| `gatepass` | **ใบนําอุปกรณ์ ทรัพย์สิน ออกนอกพื้นที่ (PT3-FM-SEC-1012)** | แบบฟอร์มทางการขออนุญาตนำทรัพย์สินออกนอกพื้นที่โรงพยาบาล (ตาราง 10 แถวบริบูรณ์ + 5 ลายเซ็น) |

### วิธีการใช้งาน Print Center:
1. **เลือกแบบฟอร์ม:** เลือกรูปแบบจากกล่องตัวเลือกด้านบน ระบบจะดึงข้อมูลครุภัณฑ์ที่สแกนอยู่มาเติมลงในแบบฟอร์มให้อัตโนมัติ
2. **ปรับแต่งข้อมูลด่วน (Quick-Edit Drawer):** คลิกปุ่ม `[ปรับแต่งข้อมูลฟอร์ม]` เพื่อเปิดแผงแก้ไขข้อมูล:
   - เลขที่ Job / เอกสารอ้างอิง
   - ชื่อผู้ติดต่อ และเบอร์โทรศัพท์
   - อาการเสีย / ปัญหาที่ตรวจพบ
   - ชื่อช่างผู้ดำเนินการ
   - วิธีการแก้ไข / ผลการทดสอบ
3. **ระบบพรีวิวสด (Live Interactive Preview):** เมื่อพิมพ์ข้อมูลในช่อง Quick Edit ตัวหนังสือในกระดาษแบบฟอร์มจะอัปเดตแบบเรียลไทม์ทันที
4. **สั่งพิมพ์ (Print / Save as PDF):** คลิกปุ่ม `[สั่งพิมพ์เอกสาร / บันทึก PDF]`
   - เบราว์เซอร์จะเปิดหน้าต่าง Print Preview
   - สามารถเลือกเครื่องพิมพ์กระดาษจริง หรือเลือก **"Save as PDF"** เพื่อบันทึกเป็นไฟล์ดิจิทัล

## การรองรับภาษาไทยข้ามระบบ (Cross-Platform Font Resolution)

ระบบสร้างเอกสาร PDFKit ฝั่งเซิร์ฟเวอร์ได้รับการออกแบบให้ทำงานได้อย่างถูกต้องทั้งบน Windows, Linux และ Docker ผ่านตัวจัดการฟอนต์ `utils/fontResolver.js`:
- ตรวจสอบฟอนต์โครงการใน `fonts/tahoma.ttf`
- ตรวจสอบฟอนต์ Windows: `C:\Windows\Fonts\tahoma.ttf` และ `tahomabd.ttf`
- ตรวจสอบฟอนต์ Linux / Docker: `/usr/share/fonts/truetype/dejavu/` และ `liberation/`
- หากไม่พบฟอนต์ไทย ระบบจะใช้ Helvetica เป็นตัวสำรองอย่างปลอดภัยโดยไม่ทำให้เซิร์ฟเวอร์ขัดข้อง
