# 05 — PDPA-Aware Data Sanitization Safeguard

กลุ่มผู้ใช้: IT Staff / Admin

---

## ฟีเจอร์นี้คืออะไร?

ระบบบังคับตรวจสอบว่าครุภัณฑ์ที่จัดเก็บข้อมูล (Storage Media) เช่น
HDD, SSD, Computer จะต้องผ่านการ "ล้างข้อมูล" หรือ "ถอดฮาร์ดไดร์ฟ"
ก่อนส่งให้บุคคลภายนอก (ศูนย์บริการ/Vendor)

ตามมาตรฐาน: ISO/IEC 27001 + พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)

---

## เมื่อไหร่ที่แผง PDPA จะปรากฏ?

แผง PDPA Safeguard จะแสดงขึ้นเมื่อ:
1. สแกนครุภัณฑ์ใน IT Portal
2. ครุภัณฑ์นั้นมี flag "sanitization_required = true"
   (เพิ่มตอนลงทะเบียนครุภัณฑ์ → ช่อง "ต้องทำความสะอาดข้อมูล")
3. ครุภัณฑ์สถานะ Broken และกำลังจะส่งเคลม

---

## ขั้นตอนการยืนยัน PDPA Sanitization

### Step 1: อ่านคำเตือน
แผงสีแดงจะแสดง:
"ครุภัณฑ์นี้เป็นอุปกรณ์บันทึกข้อมูลหลัก (Storage Media) ที่อาจมีข้อมูลประวัติผู้ป่วย..."
"ต้องทำความสะอาดข้อมูล หรือถอดฮาร์ดไดร์ฟออกก่อนส่งไปยังบุคคลภายนอก"

### Step 2: กดสวิตช์ยืนยัน
กด Toggle Switch:
"ฉันขอยืนยันว่าได้ถอดสื่อบันทึกข้อมูล หรือล้างข้อมูลความปลอดภัยเรียบร้อยแล้ว"

### Step 3: พิมพ์รหัสยืนยัน
ในช่อง "รหัสยืนยันความปลอดภัย" พิมพ์:
- คำว่า "WIPED" (ตัวใหญ่ทั้งหมด)  ---- หรือ ----
- รหัสครุภัณฑ์ (Asset Tag) ของเครื่องนั้น

### Step 4: กดยืนยัน
กดปุ่ม [ยืนยันความปลอดภัยข้อมูล (Confirm Data Wiped)]

- ระบบบันทึก data_wiped_confirmed = true ในฐานข้อมูล
- บันทึก Audit Log
- ปลดล็อกให้สามารถดำเนินการส่งเคลมต่อได้

---

## ตัวอย่างรหัสที่ยอมรับ

ครุภัณฑ์รหัส CIT-2022-TAB-03:
- พิมพ์ "WIPED" → ผ่าน
- พิมพ์ "CIT-2022-TAB-03" → ผ่าน
- พิมพ์ "wiped" → ผ่าน (ระบบแปลงเป็น uppercase อัตโนมัติ)
- พิมพ์อย่างอื่น → ไม่ผ่าน

---

## ข้ามขั้นตอนได้ไหม?

ไม่ได้ สำหรับครุภัณฑ์ที่ sanitization_required = true
ระบบจะบังคับยืนยันก่อนส่งเคลม ไม่มีทางข้ามได้

สำหรับครุภัณฑ์ที่ไม่ต้องการล้างข้อมูล (เช่น Monitor, Scanner)
แผงนี้จะไม่ปรากฏ

---

## บันทึกใน PDF Report

เมื่อออก PDF ใบเคลม จะมีส่วน:
"3. มาตรการความปลอดภัยและการตรวจสอบข้อมูล (PDPA Compliance)"
ระบุว่าครุภัณฑ์ผ่านการยืนยัน Sanitization Authorization แล้ว
