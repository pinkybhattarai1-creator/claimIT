# 05 — PDPA-Aware Data Sanitization Safeguard

กลุ่มผู้ใช้: IT Staff / Admin

---

## ฟีเจอร์นี้คืออะไร?

ระบบบังคับตรวจสอบว่าครุภัณฑ์ที่จัดเก็บข้อมูล (Storage Media) เช่น
HDD, SSD, Computer จะต้องผ่านการ "ล้างข้อมูล" หรือ "ถอดฮาร์ดไดร์ฟ"
ก่อนส่งให้บุคคลภายนอก (ศูนย์บริการ/Vendor)

ตามมาตรฐาน: ISO/IEC 27001 + พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)

---

## เมื่อไหร่ที่แผง PDPA จะปรากฏ?

แผง PDPA Safeguard จะแสดงขึ้นเมื่อ:
1. สแกนครุภัณฑ์ใน IT Portal
2. ครุภัณฑ์มี flag "sanitization_required = true"
   (ตั้งค่าตอนลงทะเบียนครุภัณฑ์ → checkbox "ต้องทำความสะอาดข้อมูล")
3. ครุภัณฑ์สถานะ Broken และกำลังจะส่งเคลม

---

## ขั้นตอนการยืนยัน PDPA Sanitization

### Step 1: อ่านคำเตือน
แผงสีแดงแสดง:
"ครุภัณฑ์นี้เป็นอุปกรณ์บันทึกข้อมูลหลัก (Storage Media) ที่อาจมีข้อมูลประวัติผู้ป่วย..."
"ต้องทำความสะอาดข้อมูล หรือถอดฮาร์ดไดร์ฟออกก่อนส่งไปยังบุคคลภายนอก"

### Step 2: กดสวิตช์ยืนยัน
กด Toggle Switch:
"ฉันขอยืนยันว่าได้ถอดสื่อบันทึกข้อมูล หรือล้างข้อมูลความปลอดภัยเรียบร้อยแล้ว"

### Step 3: พิมพ์รหัสยืนยัน (Wipe Authorization Code)
ระบบยอมรับรหัสต่อไปนี้ (ตรวจสอบโดย Backend):

รหัสที่ยอมรับ:
- WIPED                 (แนะนำ)
- CONFIRM-WIPE
- WIPE-CONFIRM
- 9999
- รหัสครุภัณฑ์ (Asset Tag) ของเครื่องนั้น

ตัวอักษรไม่ต้องกังวลเรื่องตัวพิมพ์ใหญ่/เล็ก (ระบบแปลงเป็น uppercase อัตโนมัติ)

### Step 4: กดยืนยัน
กดปุ่ม [ยืนยันความปลอดภัยข้อมูล (Confirm Data Wiped)]

- ระบบบันทึก rma_claims.data_wiped_confirmed = 1
- บันทึก data_wiped_by (username), data_wiped_at (timestamp)
- อัปเดตสถานะครุภัณฑ์เป็น "Sanitized"
- บันทึก Audit Log
- ปลดล็อกให้สามารถดำเนินการส่งเคลมต่อได้

---

## ตัวอย่างรหัสที่ยอมรับ

ครุภัณฑ์รหัส CIT-2022-TAB-03:
- พิมพ์ "WIPED"             → ผ่าน
- พิมพ์ "CONFIRM-WIPE"      → ผ่าน
- พิมพ์ "WIPE-CONFIRM"      → ผ่าน
- พิมพ์ "9999"              → ผ่าน
- พิมพ์ "CIT-2022-TAB-03"  → ผ่าน
- พิมพ์ "wiped"             → ผ่าน (auto-uppercase)
- พิมพ์อย่างอื่น            → ไม่ผ่าน (error 400)

---

## PDPA Gate ใน Backend

ระบบตรวจสอบ PDPA ที่ Backend ก่อนสร้างใบเคลม (POST /api/assets/claim):
ถ้า sanitization_required = 1 AND data_wiped_confirmed ≠ 1 → ปฏิเสธ error 400:
"PDPA Security Gate Block: อุปกรณ์นี้เป็นอุปกรณ์บันทึกข้อมูลหลัก..."

ป้องกันไม่ให้ส่งเคลมโดยไม่ผ่าน PDPA แม้จะพยายามข้าม UI

---

## ข้ามขั้นตอนได้ไหม?

ไม่ได้ — Backend ตรวจสอบทุกครั้ง
สำหรับครุภัณฑ์ที่ไม่ต้องการล้างข้อมูล (เช่น Monitor, Scanner)
แผงนี้จะไม่ปรากฏ
