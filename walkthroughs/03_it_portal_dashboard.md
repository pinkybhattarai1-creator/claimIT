# 03 — IT Portal Dashboard (ศูนย์ควบคุมเจ้าหน้าที่ไอที)

> **กลุ่มผู้ใช้:** IT Staff / IT Administrator | **เวลาอ่าน:** ~6 นาที

---

## IT Portal คืออะไร?

**IT Portal** เป็นศูนย์กลางการบริหารจัดการวงจรชีวิตของครุภัณฑ์ไอที (IT Lifecycle Management) ครอบคลุมตั้งแต่การรับแจ้งซ่อม การตรวจสอบเงื่อนไขรับประกัน การประเมินความคุ้มค่า การกำกับดูแลความปลอดภัยข้อมูลตาม PDPA การรวมกลุ่มส่งเคลมศูนย์บริการ (Multi-Asset RMA) การรับเครื่องคืน และการแทงจำหน่าย (EOL Salvage)

---

## การเข้าใช้งาน IT Portal

- ล็อกอินด้วยบัญชีที่มีสิทธิ์ `admin` (เช่น `admin` / `admin123`)
- คลิกปุ่ม **[IT Portal]** บนแถบเมนูด้านบน (ปุ่มนี้จะแสดงเฉพาะผู้ใช้ระดับ Admin เท่านั้น)

---

## โครงสร้างหน้าจอหลักของ IT Portal

หน้าจอ IT Portal แบ่งออกเป็น 5 ส่วนสำคัญอย่างชัดเจน:

```text
┌─────────────────────────────────────────────────────────────┐
│ 1. แถบสรุปสถิติระบบภาพรวม (Stats Dashboard Row)              │
├──────────────────────────────┬──────────────────────────────┤
│ 2. แผงสแกนค้นหาครุภัณฑ์       │ 3. แผงปฏิบัติการงานเคลม        │
│    (Smart Scanner Console)   │    (RMA Action Board)        │
├──────────────────────────────┴──────────────────────────────┤
│ 4. ตารางคลังครุภัณฑ์ทั้งหมด (Asset Inventory Table)          │
├─────────────────────────────────────────────────────────────┤
│ 5. แผงบริหารงานเคลมแบบกลุ่ม (Multi-Asset Claims Board)       │
├──────────────────────────────┬──────────────────────────────┤
│ 6. การจัดการผู้ใช้งาน (Users)  │ 7. การตั้งค่าระบบ (Configs)   │
├──────────────────────────────┴──────────────────────────────┤
│ 8. บันทึกประวัติการเคลื่อนย้ายและความปลอดภัย (Audit Trail)     │
└─────────────────────────────────────────────────────────────┘
```

---

## 1. การ์ดสรุปสถิติระบบ (Stats Dashboard)

ด้านบนสุดประกอบด้วยการ์ดสถิติ 4 ใบ อัปเดตข้อมูลแบบ Real-time:

| การ์ดสถิติ | สีที่แสดง | ความหมายและแหล่งข้อมูล |
|---|---|---|
| **ทรัพย์สินทั้งหมด** | สีน้ำเงิน | จำนวนครุภัณฑ์ที่มีสถานะ Active ทั้งหมดในระบบ |
| **เครื่องใช้งานปกติ** | สีเขียว | จำนวนครุภัณฑ์สถานะ `Working` พร้อมใช้งานตามวอร์ด |
| **รอดำเนินการเคลม** | สีแดง | จำนวนครุภัณฑ์สถานะ `Broken` หรือหมดประกันที่ต้องจัดการ |
| **รอศูนย์เข้ามารับ** | สีเหลือง | จำนวนครุภัณฑ์สถานะ `Pending Pickup` ที่รอ Vendor รับไปซ่อม |

---

## 2. แผงสแกนและค้นหา (Smart Scanner Console)

ตั้งอยู่ด้านซ้ายของหน้าจอ รองรับการสแกนด้วยบาร์โค้ดสแกนเนอร์และการพิมพ์:
- **Anti-Typo Switch:** สวิตช์บังคับใช้หัวอ่านสแกนเนอร์ความเร็วสูง ป้องกันการพิมพ์ผิด
- **Offline Parser Analytics:** ถอดรหัสโครงสร้าง Tag ทันที
- **Fuzzy Search Suggestion:** แนะนำรหัสที่ถูกต้องหากยิงหรือพิมพ์ตกหล่น
- **Auto-Open Add Asset:** หากสแกนรหัสที่ยังไม่เคยมีในระบบ ระบบจะเปิดหน้าต่าง "เพิ่มครุภัณฑ์ใหม่" ให้ทันทีพร้อมใส่รหัสนั้นไว้ให้อัตโนมัติ

---

## 3. แผงปฏิบัติการงานเคลม (RMA Action Board)

เมื่อเลือกหรือสแกนครุภัณฑ์ขึ้นมา แผงด้านขวาจะปรับเปลี่ยนตามสถานะของเครื่องนั้นๆ โดยอัตโนมัติ:
1. **ข้อมูลครุภัณฑ์:** รหัส, ชื่ออุปกรณ์, ซีเรียล, วันหมดประกัน, มูลค่าประเมิน
2. **แถบประเมินความคุ้มค่า (Viability Banner):** วิเคราะห์ว่าคุ้มที่จะส่งซ่อมหรือไม่ (สีเขียว = คุ้มค่า / สีแดง = ไม่คุ้มค่า)
3. **ปุ่มดาวน์โหลด PDF & พิมพ์ฟอร์ม:** ดาวน์โหลดรายงาน PDF ของเครื่องนั้น หรือเปิด Print Center
4. **แผงมาตรการ PDPA (Storage Media Safeguard):** ปรากฏขึ้นเมื่อเป็นอุปกรณ์จัดเก็บข้อมูล บังคับยืนยันการล้างข้อมูลก่อนส่งเคลม
5. **ฟอร์มสร้างใบส่งเคลม (RMA Initiation Form):** เลือกศูนย์บริการ, กรอกหมายเลข RMA, ระบุวันนัดรับ และพรีวิวอีเมลแจ้งเตือน
6. **แผงจัดการ EOL / ซากอุปกรณ์ (Salvage Console):** สำหรับเครื่องที่ไม่คุ้มค่าส่งซ่อม (รอขายทอดตลาด / บริจาค / แทงจำหน่าย)
7. **ปุ่มรับเครื่องคืน (Return to Stock):** สำหรับเครื่องที่ส่งซ่อมเสร็จแล้วและนำกลับเข้าคลัง

---

## 4. ตารางคลังครุภัณฑ์ทั้งหมด (Asset Inventory Table)

แสดงรายการครุภัณฑ์ทั้งหมดในระบบพร้อมฟังก์ชันอำนวยความสะดวก:
- **Click-to-Select:** คลิกที่แถวใดก็ได้เพื่อโหลดข้อมูลเข้าสู่แผง Action Board ด้านบนทันที
- **ปุ่ม [📄 PDF] ในแถว:** คลิกเพื่อดาวน์โหลด PDF ใบงานเคลมของครุภัณฑ์นั้นได้ทันทีใน 1 คลิก
- **ตัวกรองสถานะ (Status Filter):** กรองดูเฉพาะสถานะที่ต้องการ (ปกติ, ชำรุด, รอศูนย์รับ, ขาย, บริจาค, แทงจำหน่าย)
- **คัดลอกข้อมูล (Copy TSV):** คัดลอกตารางไปวางลงใน Excel ได้ทันที
- **ส่งออก Excel ทั้งระบบ:** ดาวน์โหลดไฟล์ `.xls` รวม 5 ชีต
- **ระบบแบ่งหน้า (Pagination):** แสดงผล 50 รายการต่อหน้า พร้อมแสดงจำนวนรวม

---

## 5. ตารางจัดการใบส่งเคลม (Multi-Asset Claims Board)

ระบบงานเคลมใหม่ที่รองรับการรวมเครื่องเคลม 1–5 รายการ:
- แสดงหมายเลขใบเคลม (เช่น `CLM-2026-001`), ชื่อศูนย์บริการ, จำนวนเครื่องในใบเคลม, วันที่, คะแนนความคุ้มค่า, และป้ายสถานะ (DRAFT, VIABLE, SUBMITTED, VENDOR_RESPONSE, RETURNED, CLOSED, CANCELLED)
- **ปุ่ม [+ สร้างใบเคลมใหม่]:** เปิดหน้าต่างสร้างใบเคลมแบบรวมหลายชิ้น
- **ปุ่ม [📋 รายละเอียด]:** เปิดดูรายการเครื่องทั้งหมดในใบเคลม เปลี่ยนสถานะงานเคลม และแนบ/ดูไฟล์หลักฐาน
- **ปุ่ม [📄 PDF]:** ดาวน์โหลดรายงานใบส่งเคลมฉบับเต็มของใบเคลมนั้น

---

## 6. แผงจัดการผู้ใช้ (User Management) & การตั้งค่า (Configurations)

- **จัดการผู้ใช้งาน:** จัดกลุ่มระหว่าง Administrators และ Staff Members, สร้างผู้ใช้ใหม่, กำหนดบทบาท, ระงับบัญชี และรีเซ็ตรหัสผ่าน
- **การตั้งค่าระบบ:** จัดการรายการแบรนด์ (พร้อมขั้นตอนการเคลม Brand Procedures), หมวดหมู่ครุภัณฑ์ และรายชื่อสถานที่ติดตั้ง/วอร์ด

---

## 7. ประวัติการเคลื่อนย้ายและความปลอดภัย (Audit Trail)

บันทึกทุกเหตุการณ์ที่เกิดขึ้นในระบบแบบเรียลไทม์:
- มีตัวกรองด่วน: ทั้งหมด, วันนี้, เมื่อวาน, 7 วัน, 30 วัน
- กรองตามช่วงวันที่ และค้นหาข้อความแบบ Live Search
- แถบสรุปปริมาณงานรายวัน (Daily Case Volume Badge) และสถิติวันที่มีงานสูงสุด
