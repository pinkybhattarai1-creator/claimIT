# 03 — IT Portal Dashboard (หน้าหลักเจ้าหน้าที่ IT)

กลุ่มผู้ใช้: IT Staff / Admin

---

## IT Portal คืออะไร?

หน้าหลักสำหรับเจ้าหน้าที่ IT จัดการทุกอย่างในระบบ:
- ดูสถิติสรุปรวม (Dashboard Stats)
- สแกนและจัดการครุภัณฑ์
- สร้างใบส่งเคลม (RMA)
- ดูรายการครุภัณฑ์ทั้งหมด
- จัดการผู้ใช้งาน
- ตั้งค่าระบบ
- ดู Audit Trail

---

## แถบนำทางย่อยแบบตรึงด้านบน (Sticky Sub-Navigation Bar)

IT Portal จัดระเบียบการทำงานด้วย **Sticky Sub-Navigation Bar** (`position: sticky; top: 68px;`) ที่ตรึงอยู่ด้านบน ไม่เลื่อนหลุดสายตา และขจัดปัญหาหน้ายาว (Zero Infinite Scrolling):

| แท็บ | เนื้อหาการทำงาน |
|---|---|
| 🔍 **แผงสแกน & จัดการเคลม** | สถิติ 4 ใบ, แผงสแกนเนอร์, RMA Action Board, การแนบหลักฐาน |
| 📑 **รายการใบส่งเคลม** | ตารางใบเคลมแบบ Multi-Asset, กรองสถานะ, อนุมัติ/ส่งศูนย์/รับคืน |
| 📋 **ทะเบียนครุภัณฑ์ไอที** | คลังครุภัณฑ์ทั้งหมด, กรองสถานะใกล้หมดประกัน 6 เดือน (`expiring_6m`), แสดงวันหมดประกันสองปี (พ.ศ./ค.ศ.), ส่งออก Excel/TSV, เพิ่มครุภัณฑ์ใหม่ |
| 📜 **ประวัติ & Audit Trail** | บันทึกการเคลื่อนย้ายและเปลี่ยนสถานะแบบล็อกถาวร พร้อม Tracking Code และแสดงเวลาแบบสองปี (พ.ศ./ค.ศ.) |
| ⚙️ **ไปที่หน้าตั้งค่าระบบ →** | ปุ่มทางลัดสลับไปยังส่วน **[⚙️ ตั้งค่า & จัดการระบบ (System Admin)]** ที่แยกออกมาเป็นส่วนเฉพาะด้านบน |

ทุกตารางในระบบถูกกำหนดให้เลื่อนภายในกล่องตารางเอง (`max-height: calc(100vh - 290px); overflow-y: auto;`) พร้อม **Sticky Table Headers** ทำให้หน้าเว็บคงขนาดกะทัดรัดและใช้งานได้สะดวกบนทุกขนาดหน้าจอโดยไม่เกิด Scrollbar ของหน้าต่างหลัก

## การ์ดสถิติ (Stats Dashboard)

ในแท็บ "แผงสแกน & จัดการเคลม" มีการ์ดสถิติ 4 ใบ:

| การ์ด | ข้อมูลที่แสดง |
|---|---|
| 📦 ทรัพย์สินทั้งหมด | จำนวนครุภัณฑ์ทั้งหมดในระบบ |
| 🟢 เครื่องใช้งานปกติ (สีเขียว) | จำนวนครุภัณฑ์พร้อมใช้งานประจำแผนก |
| 🔴 รอดำเนินการเคลม (สีแดง) | จำนวนที่ชำรุด/รอส่งเคลม |
| 🟡 รอศูนย์เข้ามารับ (สีเหลือง) | จำนวน Pending Pickup |

ตัวเลขอัปเดตอัตโนมัติทุกครั้งที่โหลดหน้าหรือเปลี่ยนสถานะครุภัณฑ์
- Audit Trail Panel → ดู 13_audit_trail.md
