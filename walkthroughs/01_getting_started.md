# 01 — เริ่มต้นใช้งาน ClaimIT (Getting Started)

กลุ่มผู้ใช้: ทุกคน (Staff & Admin) | เวลาอ่าน: ~5 นาที

---

## ระบบนี้คืออะไร?

ClaimIT คือระบบบริหารจัดการการรับประกันและส่งเคลมครุภัณฑ์ไอที (RMA) สำหรับโรงพยาบาล

---

## ขั้นตอนที่ 1: เข้าถึงระบบ

เปิด Browser ที่:
  http://[server-ip]:8847
  หรือ http://localhost:8847

---

## ขั้นตอนที่ 2: Security Gate (ประตูรักษาความปลอดภัย)

ก่อนหน้าล็อกอิน ระบบมี "Security Gate" — หน้าจอขอรหัสผ่านเข้าแอป
รหัสผ่านเริ่มต้น: 1 (กำหนดใน .env ด้วย APP_PASSCODE)

หากผ่าน Gate แล้ว ระบบจะตั้ง Cookie claimit_gate=1 (หมดอายุ 30 วัน)
ครั้งต่อไปไม่ต้องกรอก Gate อีก

---

## ขั้นตอนที่ 3: ล็อกอิน (Login)

1. หน้าแรกแสดง "ยินดีต้อนรับสู่ ClaimIT"
2. กรอก Username และ Password หรือกดปุ่ม **เข้าสู่ระบบด่วน 1-Click (Fast Login)**
3. มีปุ่มกดเข้าสู่ระบบด่วน 2 บัญชีหลักตามสิทธิ์การใช้งาน:
   - **👑 แอดมิน (admin)**: สิทธิ์ผู้ดูแลระบบ (IT Administrator) เข้าถึงทุกฟังก์ชันรวมถึงทะเบียนครุภัณฑ์ จัดการเคลม ตั้งค่าระบบ และจัดการผู้ใช้งาน
   - **🩺 เจ้าหน้าที่ (staff)**: สิทธิ์ช่างไอทีภาคสนาม (IT Support Staff) สแกนบาร์โค้ด ตรวจสอบประกัน แจ้งชำรุด และติดตามสถานะงานซ่อม

4. **การเชื่อมต่อผ่าน iPhone / มือถือใน รพ.**:
   - แถบใต้ฟอร์มล็อกอินจะแสดง URL เชื่อมต่อผ่านเครือข่าย รพ. อัตโนมัติ (เช่น `http://10.33.43.xx:8847`)
   - มีปุ่ม [📋 คัดลอก] เพื่อนำไปเปิดใน Safari / Chrome บน iPhone ได้ทันที
   - สามารถกด [⚙️ เปลี่ยน IP] เพื่อระบุ IP Address เองได้หากใช้วงเครือข่ายเฉพาะ

ข้อสำคัญ:
- Token หมดอายุใน 8 ชั่วโมง
- บัญชีที่ถูก Deactivate ล็อกอินไม่ได้
- Login ล้มเหลวเกิน 15 ครั้งใน 15 นาที → ถูก Block (Rate Limiting)
- ทุก Login สำเร็จ/ล้มเหลวถูกบันทึกใน Audit Log
- รหัสผ่าน Legacy (pbkdf2) จะถูก migrate ไปเป็น bcrypt อัตโนมัติเมื่อล็อกอิน

---

## ขั้นตอนที่ 4: หน้าจอหลังล็อกอิน & แถบเมนูด้านบน (Navigation & Self Profile Edit)

Nav Bar ด้านบนประกอบด้วย:
- **แบรนด์และชื่อระบบ:** ClaimIT (Hospital IT Warranty & RMA)
- **ป้ายเตือนประกันใกล้หมดอายุ (Interactive Warranty Expiry Badge):** `⚠️ X ใกล้หมดประกัน` (`#warranty-expiring-badge`) คลิกเพื่อเปิดตารางครุภัณฑ์ที่ใกล้หมดประกันทันที
- **ปุ่มหลัก 3 ส่วนการทำงาน:**
  - `🛠️ ระบบแจ้งซ่อมประจำแผนก (Staff)`: สำหรับสแกน ตรวจเช็คประกัน และแจ้งซ่อมจากวอร์ด
  - `💻 ศูนย์ซ่อมและเคลมประกัน (IT)`: สำหรับเปิดใบเคลม RMA, ทะเบียนครุภัณฑ์ และ Audit Trail (เฉพาะ Admin/IT)
  - `⚙️ ตั้งค่าระบบและจัดการผู้ใช้งาน`: จัดการแบรนด์, หมวดหมู่, ผังอาคาร, จัดการผู้ใช้, ข้อเสนอแนะ และสำรองข้อมูล (เฉพาะ Admin)
- **วิดเจ็ตโปรไฟล์ผู้ใช้:** แสดงชื่อ + Role และแผนกปัจจุบัน สามารถคลิกเพื่อ **"✏️ แก้ไขชื่อ"** และแผนกของตนเองได้ทันที โดยระบบจะออก JWT Token ใหม่แบบ Real-time
- **ปุ่มเครื่องมือด่วน:**
  - `📊 ข้อมูลด่วน (Quick Sidebar)`: เปิดแผงข้อมูลและสายด่วน IT Helpdesk
  - `📊 ส่งออก Excel`: ดาวน์โหลดรายงาน SpreadsheetML
  - `🚪 ออกจากระบบ (Logout)`: ล้างโทเค็นและออกจากระบบ

Staff ที่ไม่ใช่ Admin จะเห็นปุ่มทั้ง 3 ส่วนเพื่อความโปร่งใสของโครงสร้างระบบ แต่หากกดส่วนของ Admin จะได้รับแจ้งเตือน
"เฉพาะเจ้าหน้าที่ผู้ดูแลระบบ (Admin) เท่านั้น"

---

## Session Auto-Restore

ถ้ายัง login อยู่ (มี token ใน localStorage) และ refresh หน้า:
- Admin → ไป IT Portal อัตโนมัติ
- Staff → ไป Staff Portal อัตโนมัติ

---

## เปลี่ยนรหัสผ่านตัวเอง

POST /api/auth/change-password
Body: { username, current_password, new_password }
ผู้ใช้สามารถเปลี่ยนรหัสผ่านตัวเองได้โดยไม่ต้องขอ Admin

## เข้าสู่ระบบด่วนตามสิทธิ์ (Fast Login 1-Click)

หน้าเข้าสู่ระบบมีปุ่ม Fast Login 2 บัญชีหลักเพื่อความสะดวกในการทดสอบและสลับสิทธิ์การทำงาน:
- 👑 **`แอดมิน (admin)`**: เข้าสู่ระบบด้วยสิทธิ์ผู้ดูแลระบบ (IT Administrator) ทันที
- 🩺 **`เจ้าหน้าที่ (staff)`**: เข้าสู่ระบบด้วยสิทธิ์ช่างเทคนิคสารสนเทศ (IT Support Staff) ทันที

คลิกปุ่มใดก็ได้เพื่อเข้าสู่ระบบตามสิทธิ์ทันทีแบบ 1-Click โดยไม่ต้องพิมพ์รหัสผ่าน

---

## Health Check

GET /health → ดูสถานะเซิร์ฟเวอร์และฐานข้อมูล:
  { status: 'UP', database: 'CONNECTED', uptime: 1234, ... }

---

## ออกจากระบบ (Logout)

กดปุ่ม "ออกจากระบบ" — ระบบล้าง JWT Token และกลับไปหน้า Login
