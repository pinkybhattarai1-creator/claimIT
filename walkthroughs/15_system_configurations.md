# 15 — การตั้งค่าระบบและผังอาคารสถานพยาบาล (System Configurations & Hospital Layout)

กลุ่มผู้ใช้: ผู้ดูแลระบบสารสนเทศ (Admin) เท่านั้น

---

## ภาพรวมสถาปัตยกรรม (Architecture Overview)

ระบบบริหารจัดการครุภัณฑ์สารสนเทศ ClaimIT แยกหมวดหมู่การตั้งค่าระบบหลักออกจากกันอย่างเป็นสัดส่วน ไม่ซ้อนทับกัน (Non-stacking Sub-tabs) พร้อมเชื่อมโยง **ผังอาคารและจุดบริการสถานพยาบาล (Hospital Layout Directory)** เข้ากับระบบลงทะเบียนครุภัณฑ์ เพื่อให้เจ้าหน้าที่สามารถเลือกสถานที่ติดตั้งและแผนกได้อย่างแม่นยำ เป็นมาตรฐานเดียวกันทั่วทั้งโรงพยาบาล

ระบบออกแบบด้วยหลักการ **Zero Database Schema Change (0 การแก้ไขโครงสร้างฐานข้อมูล)** ทำให้การเพิ่มหรือแก้ไขแผนก อาคาร ชั้น แบรนด์ หรือหมวดหมู่ เป็นไปอย่างยืดหยุ่นผ่านตาราง `configurations` โดยไม่ต้องรัน Database Migration ใดๆ

## การจัดหมวดหมู่หน้าจอตั้งค่าระบบ (Separated Navigation Tabs)

เมื่อเข้าสู่เมนู **[⚙️ ตั้งค่าระบบและจัดการผู้ใช้งาน (System Admin)]** ระบบจะแบ่งหมวดหมู่การตั้งค่าออกเป็น 6 แท็บย่อยอิสระ จัดวางบนแถวเดียวอย่างเป็นระเบียบพร้อมป้ายจำนวนข้อมูล (Badge Pills):

1. **🏷️ แบรนด์และคู่มือศูนย์บริการ (Brands & RMA Guides)**
   - จัดการรายชื่อผู้ผลิต/ตัวแทนจำหน่าย (Vendors): Dell, HP, Lenovo, Apple, Zebra, Acer, Brother ฯลฯ
   - บันทึกคู่มือและขั้นตอนการส่งเคลมเฉพาะของแต่ละแบรนด์ (RMA Procedures, เบอร์ Call Center, เงื่อนไข Onsite Service)
   - แสดงขั้นตอนอัตโนมัติใน RMA Workflow เมื่อเลือกแบรนด์นั้นๆ

2. **💻 หมวดหมู่อุปกรณ์ (Device Categories)**
   - จัดการประเภทครุภัณฑ์: Computer, Monitor, Printer, Scanner, Network Switch, Tablet, UPS, Clinical IT Display ฯลฯ
   - **เรียงลำดับ ID จากน้อยไปมาก:** จัดเรียงตามลำดับรหัส ID ตัวเลขจากน้อยไปมาก (Natural Sequential Order: 6, 7, 8, 9, 10, 11, 12, 13...) แก้ปัญหาตัวเลขสลับกัน
   - **ป้ายกำกับภาษาไทย (Bilingual Thai Labels):** แสดงคำอธิบายภาษาไทยควบคู่ทุกหมวดหมู่ (เช่น *คอมพิวเตอร์และโน้ตบุ๊ก*, *จอมอนิเตอร์ตรวจวินิจฉัยทางการแพทย์*, *รถเข็นจ่ายยาและพยาบาลอัจฉริยะ*)
   - มีปุ่มทางลัด **`+ เพิ่มหมวดหมู่อุปกรณ์`** เพื่อเปิด Modal ที่เลือกประเภท `category` ให้อัตโนมัติ

3. **🏥 แผนกและสถานที่ติดตั้ง (Locations & Wards — Authoritative Hospital Directory)**
   - สถาปัตยกรรมทางกายภาพของอาคารโรงพยาบาลและหอผู้ป่วยถือเป็นโครงสร้างถาวรและไม่ซ้ำซ้อน
   - **โครงสร้างผังอาคารเดียวที่สมบูรณ์ (Single Authoritative Source):** ใช้โครงสร้างอาคาร 1 (ชั้น 21 ถึง ชั้น D) และอาคาร Call Center เป็นสารบบอ้างอิงสถานที่เพียงแหล่งเดียว ป้องกันข้อมูลขัดแย้ง (เช่น กรณี Ward 20 ซ้ำซ้อนที่ชั้น 2)
   - **กำจัดการวางตารางซ้อนทับ:** ตัดปุ่มเพิ่มสถานที่และตัดตารางซ้ำซ้อนด้านล่างออกทั้งหมด นำเสนอในรูปแบบการ์ดสารบบผังอาคารสถานพยาบาลที่สวยงาม กะทัดรัด และคลิกเพื่อนำไปใช้ได้ทันที

4. **👥 จัดการผู้ใช้งานระบบ (User Management)**
   - แยกตารางแสดงผลระหว่าง **👨‍💻 ช่างเทคนิคสารสนเทศ (IT Staff)** และ **🛡️ ผู้ดูแลระบบ (Admins)** ออกจากกันเป็นสัดส่วน ไม่ซ้อนทับกัน พร้อมตัวกรองบทบาท (Role Switcher Pills)
   - บัญชีที่สร้างใหม่มีนโยบายความปลอดภัยบังคับเปลี่ยนรหัสผ่านครั้งแรก (`must_change_password = 1`)

5. **💬 ข้อเสนอแนะและการแจ้งปัญหาจากผู้ใช้งาน (Feedback & Bugs — `#tab-cfg-feedback`)**
   - แผงควบคุมและตรวจสอบข้อคิดเห็น/รายงานข้อผิดพลาดจากผู้ใช้งานแบบเรียลไทม์
   - ฟิลเตอร์แยกตามประเภทปัญหา: ทั้งหมด, 🐞 แจ้งปัญหา (Bugs), 💡 ข้อเสนอแนะ (Suggestion), ❓ หน้าจอเข้าใจยาก (UX), ⏳ รอตรวจ (Open)
   - ปุ่มดาวน์โหลดรายงานสรุป: **📊 โหลด Excel (CSV)** และ **📋 โหลด FEEDBACK_LOG.md**
   - การตอบกลับของแอดมิน (Admin Reply) และการเปลี่ยนสถานะ (👀 รับทราบ / ✅ เสร็จ / 🗑️ ลบ)

6. **💾 สำรองข้อมูลและการตั้งค่าระบบ (Database Backup & IT Hotline Configuration)**
   - **สำรองฐานข้อมูล SQLite (1-Click Hot Backup):** สร้างจุดสำรองข้อมูลทันที พร้อมระบบลบไฟล์เก่าอัตโนมัติ
   - **📞 ตั้งค่าเบอร์โทรศัพท์สายด่วนไอที (IT Support Hotline Numbers):**
     - กำหนดเบอร์โทรศัพท์ติดต่อด่วนสำหรับเจ้าหน้าที่แผนกและวอร์ด (เช่น `4401, 4402, 4403`)
     - แผงพรีวิวปุ่มกดสายด่วนแบบเรียลไทม์ (Live Interactive Preview)
     - เชื่อมโยงอัตโนมัติไปยังปุ่มโทรด่วนบนหน้า Staff Portal (`#staff-hotline-container`) และแถบ Quick Hub Sidebar (`#sidebar-hotline-text`) พร้อมลิงก์ `href="tel:..."` เพื่อให้กดโทรออกได้ทันที

## การเชื่อมโยงผังอาคารกับระบบครุภัณฑ์ (Interactive Layout Picker Modal)

1. **ปุ่มเลือกสถานที่ด่วน (🏥 เลือกจากผังอาคาร)**:
   - ปรากฏเคียงข้างช่องกรอกสถานที่ในฟอร์ม **ลงทะเบียนครุภัณฑ์รายชิ้น** และ **นำเข้าครุภัณฑ์แบบกลุ่ม (Batch Intake)**
   - เมื่อคลิก จะเปิด Modal หน้าต่างผังอาคารสถานพยาบาล แสดงอาคารและชั้นทั้งหมด
   - เพียงคลิกที่ป้ายชื่อแผนก (Department Chip) ระบบจะดึงชื่อสถานที่มาตรฐานเข้าสู่ช่องกรอกทันที พร้อมปิด Modal ให้อัตโนมัติ

2. **ระบบช่วยเติมคำอัตโนมัติ (Datalist Autocomplete)**:
   - รายชื่อแผนกทั้งหมดจากผังอาคารจะถูกโหลดเข้าสู่ `<datalist id="location-suggestions">` อัตโนมัติ
   - เมื่อพิมพ์ตัวอักษร ระบบจะแนะนำแผนกที่ถูกต้อง ลดความผิดพลาดจากการสะกดชื่อไม่ตรงกัน

3. **สถาปัตยกรรมสถานพยาบาลที่คงที่และชัดเจน (Immutable Physical Architecture):**
   - ผังอาคาร ชั้น และแผนกบริการของโรงพยาบาลเป็นโครงสร้างทางกายภาพที่แน่นอน
   - ระบบจัดเก็บโครงสร้างอาคารและชั้นทั้งหมดไว้อย่างสมบูรณ์ใน `hospital_layout.js` เพื่อให้เจ้าหน้าที่ทุกแผนกและช่างเทคนิคอ้างอิงเป็นมาตรฐานเดียวกัน ป้องกันการสร้างชื่อแผนกซ้ำซ้อนหรือบันทึกผิดชั้น

## ข้อมูลตั้งค่าเริ่มต้น (Seed Configurations)

ระบบติดตั้งมาพร้อมชุดข้อมูลมาตรฐานที่ครอบคลุม:
- **แบรนด์และ RMA**: Dell, HP, Lenovo, Apple, Zebra, Acer, Brother, TSC, Generic
- **หมวดหมู่**: Computer, Clinical Workstation, Clinical IT Display, Tablet, Scanner, Printer, Network, Mobile Nursing Cart, Others
- **สถานที่**: ครอบคลุม Floor 21 ถึง Floor D ของ Main Tower และ Call Center ทั้ง 2 อาคาร
- **สายด่วน IT Support (Hotline)**: `4401, 4402, 4403` (พร้อมระบบอัปเดตและซิงค์อัตโนมัติ)

## API การตั้งค่าและจัดการระบบ (Configurations & Feedback API Reference)

| Method | Endpoint | สิทธิ์เข้าถึง | คำอธิบาย |
|---|---|---|---|
| `GET` | `/api/configurations/public-contact` | สาธารณะ (ไม่ต้องล็อกอิน) | ดึงข้อมูลติดต่อและเบอร์สายด่วน IT Hotline สำหรับหน้าล็อกอิน |
| `GET` | `/api/configurations` | ทุกบทบาท (Staff, Admin) | ดึงรายการตั้งค่าทั้งหมด (กรองตาม `?type=brand`, `?type=category`, `?type=hotline` ได้) |
| `POST` | `/api/configurations` | Admin เท่านั้น | เพิ่มการตั้งค่าใหม่ (`type`, `value`, `details`) |
| `PUT` | `/api/configurations/:id` | Admin เท่านั้น | แก้ไขข้อมูลการตั้งค่า (รวมถึงการอัปเดตเบอร์สายด่วน) |
| `DELETE` | `/api/configurations/:id` | Admin เท่านั้น | ลบรายการตั้งค่าที่ไม่ใช้งาน (Soft delete) |
| `POST` | `/api/configurations/wipe-data` | Admin เท่านั้น (Confirmation Code) | ล้างข้อมูลระบบเพื่อเริ่มต้นใหม่ (ต้องมีรหัสยืนยัน `CONFIRM-WIPE`) |
| `GET` | `/api/feedback/public` | สาธารณะ (ไม่ต้องล็อกอิน) | ดึงข้อมูลกระดานข้อเสนอแนะและปัญหาที่เปิดเผยได้ |
| `POST` | `/api/feedback` | สาธารณะ / ทุกบทบาท | ส่งข้อเสนอแนะหรือแจ้งปัญหาการใช้งานใหม่ พร้อมข้อมูลอุปกรณ์ |
| `GET` | `/api/feedback` | Admin เท่านั้น | ดึงรายการข้อเสนอแนะและปัญหาทั้งหมดในระบบสำหรับแอดมิน |
| `PUT` | `/api/feedback/:id` | Admin เท่านั้น | ปรับปรุงสถานะ (`open`, `reviewed`, `resolved`) และบันทึกคำตอบกลับของแอดมิน |
| `DELETE` | `/api/feedback/:id` | Admin เท่านั้น | ลบข้อคิดเห็นหรือปัญหาที่ไม่เหมาะสม |
| `GET` | `/api/feedback/export/csv` | Admin เท่านั้น | ส่งออกรายการข้อคิดเห็นทั้งหมดเป็นไฟล์ Excel CSV |
| `GET` | `/api/feedback/export/markdown` | Admin เท่านั้น | ส่งออกรายงานข้อคิดเห็นทั้งหมดเป็นไฟล์ FEEDBACK_LOG.md |
