# 14 — จัดการผู้ใช้งาน (User Management)

กลุ่มผู้ใช้: Admin เท่านั้น

---

## ภาพรวม

Admin สามารถสร้าง แก้ไข ระงับ และรีเซ็ตรหัสผ่านของผู้ใช้งานทั้งหมด

---

## การแยกแสดงตารางผู้ใช้งาน (Separated Non-Stacking Tables)

เข้าถึงได้ผ่านแถบเมนูด้านบน **[⚙️ ตั้งค่าระบบและจัดการผู้ใช้งาน]** → แท็บ **👥 จัดการผู้ใช้งานระบบ (User Management)**:
เพื่อไม่ให้รายชื่อผู้ใช้ซ้อนทับกันลงมาด้านล่างอย่างไร้ระเบียบ ระบบได้แบ่งตารางออกเป็น 2 การ์ดหลักชัดเจน พร้อมปุ่มสลับบทบาท:

### ปุ่มสลับมุมมองบทบาท (Role Switcher Pills):
- `🌐 ทั้งหมด (<span id="user-pill-all-count">X</span>)`: แสดงทั้งสองกลุ่ม
- `🛡️ ผู้ดูแลระบบสารสนเทศ (IT Support Administrators: <span id="user-admin-count">X</span>)`: กรองแสดงเฉพาะกลุ่ม Admin
- `👨‍💻 ช่างเทคนิคสารสนเทศ (IT Support Specialists: <span id="user-staff-count">X</span>)`: กรองแสดงเฉพาะกลุ่ม Staff

### 1. 🛡️ ผู้ดูแลระบบสารสนเทศ (IT Support Administrators)
- ตารางเฉพาะสำหรับบัญชีระดับ Admin (`#user-table-admin-body`)
- มีปุ่ม **`➕ เพิ่มผู้ดูแลระบบ (Admin)`** ที่กำหนด Role เป็น `admin` ให้อัตโนมัติ

### 2. 👨‍💻 ช่างเทคนิคสารสนเทศ (IT Support Specialists)
- ตารางเฉพาะสำหรับบัญชีระดับ Staff/ช่างเทคนิค (`#user-table-staff-body`)
- มีปุ่ม **`➕ เพิ่มช่างเทคนิค (Staff)`** ที่กำหนด Role เป็น `staff` ให้อัตโนมัติ

### คอลัมน์ในแต่ละตาราง:
- ID
- Username (แสดงสถานะ `ระงับใช้งาน` หากถูกปิดการใช้งาน)
- ชื่อ-นามสกุล
- แผนก / หน่วยงาน (Department)
- สิทธิ์การใช้งาน (ADMIN / STAFF)
- ปุ่มจัดการ (✏️ แก้ไข / 🔑 รีเซ็ตรหัสผ่าน / ⛔ ระงับ / 🔄 เปิดใช้งาน)

---

## บัญชีเริ่มต้นในระบบ (Pre-seeded Accounts: 4 IT Admins + 4 IT Staff)

ระบบติดตั้งมาพร้อม 8 บัญชีสำหรับฝ่ายไอที:
- **4 เจ้าหน้าที่ผู้ดูแลระบบ (IT Support Administrators)**: `admin`, `admin2`, `admin3`, `admin4` (รหัสผ่าน: `admin123`)
- **4 ช่างเทคนิคสารสนเทศ (IT Support Specialists)**: `staff`, `staff2`, `staff3`, `staff4` (รหัสผ่าน: `staff123`)

## เพิ่มผู้ใช้งานใหม่ (Create User)

กดปุ่ม [➕ เพิ่มผู้ใช้งานใหม่] หรือ [➕ เพิ่มผู้ดูแลระบบ] / [➕ เพิ่มช่างเทคนิค] → เปิด Modal

ข้อมูลที่ต้องกรอก:
| ฟิลด์ | ตัวอย่าง |
|---|---|
| Username | `staff5` หรือ `it_hardware` |
| Password | รหัสผ่าน (เข้ารหัสความปลอดภัยด้วย bcrypt อย่างน้อย 6 ตัวอักษร) |
| ชื่อ-นามสกุล | สมชาย ไอทีซัพพอร์ต |
| แผนก | IT Support & Operations (มี Autocomplete จากผังอาคาร) |
| Role | Staff (ช่างเทคนิค) / Admin (ผู้ดูแลระบบ) |

Roles:
- staff = ช่างเทคนิคสารสนเทศและเจ้าหน้าที่ปฏิบัติการ (เข้าถึง Staff Portal, IT Portal และแจ้งซ่อม/ติดตามสถานะ)
- admin = ผู้ดูแลระบบสารสนเทศ (เข้าถึงทุกส่วนรวมถึง IT Portal, การตั้งค่าระบบ และจัดการผู้ใช้งาน)

---

## การแก้ไขข้อมูลส่วนตัวด้วยตนเอง (Self Profile Editing)

ผู้ใช้ทุกคน (ทั้ง Admin และ Staff) สามารถคลิกปุ่ม **`✏️ แก้ไขชื่อ`** บนแถบ Header หรือคลิกที่ชื่อของตนเองเพื่อ:
- แก้ไขชื่อ-นามสกุล / ตำแหน่งที่แสดง
- แก้ไขชื่อแผนก / สังกัด
- ระบบจะอัปเดตลงฐานข้อมูลและออก JWT Token ใหม่แบบ Real-time ทันทีโดยไม่ต้องให้ Admin แก้ไขให้

---

## แก้ไขผู้ใช้งาน

PUT /api/users/:id
- แก้ไขได้: role, name, department
- ไม่สามารถเปลี่ยน username ได้

---

## ระงับการใช้งาน (Deactivate)

DELETE /api/users/:id
- เป็น Soft Delete (is_deleted = 1, is_active = 0)
- ผู้ใช้ไม่สามารถล็อกอินได้อีก
- ข้อมูลยังอยู่ในฐานข้อมูล

---

## เปิดใช้งานอีกครั้ง (Reactivate)

POST /api/users/:id/reactivate
- ตั้ง is_deleted = 0, is_active = 1
- ผู้ใช้ล็อกอินได้ปกติ

---

## รีเซ็ตรหัสผ่าน (Admin Reset Password)

POST /api/users/:id/reset-password
Body: { "new_password": "รหัสใหม่" }
- Admin สามารถรีเซ็ตรหัสผ่านได้โดยไม่ต้องรู้รหัสเดิม
- รหัสใหม่ถูกเข้ารหัสด้วย bcrypt ทันที

---

## ความปลอดภัย

- รหัสผ่านทั้งหมดเข้ารหัสด้วย bcryptjs (Cost Factor 10)
- ไม่มีการเก็บ plain text password
- JWT Token หมดอายุหลัง 8 ชั่วโมง (expiresIn: '8h')
