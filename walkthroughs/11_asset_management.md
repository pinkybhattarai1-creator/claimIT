# 11 — จัดการครุภัณฑ์ (Asset Management & Inventory)

> **กลุ่มผู้ใช้:** IT Admin (สิทธิ์จัดการเต็มรูปแบบ) / Staff (สิทธิ์ดูข้อมูล) | **เวลาอ่าน:** ~6 นาที

---

## ภาพรวม

โมดูลจัดการครุภัณฑ์ (`public/js/assets.js` และ `routes/assets.js`) คือคลังข้อมูลศูนย์กลางของอุปกรณ์คอมพิวเตอร์และเทคโนโลยีทั้งหมดในโรงพยาบาล ครอบคลุมการลงทะเบียนครุภัณฑ์ใหม่ การตรวจสอบความซ้ำซ้อน การติดตามสถานะตามจุดติดตั้ง การประเมินมูลค่าซาก และการส่งออกข้อมูล

---

## 1. ตารางคลังครุภัณฑ์ (Asset Inventory Table)

ตารางแสดงรายการอุปกรณ์ทั้งหมดในระบบพร้อมฟังก์ชันอำนวยความสะดวก:
- **Click-to-Inspect:** คลิกที่แถวของครุภัณฑ์ชิ้นใดก็ได้ ระบบจะโหลดข้อมูลของเครื่องนั้นขึ้นสู่ Smart Scanner Console และ Action Board ด้านบนทันที
- **ปุ่ม [📄 PDF] ทันที:** ที่คอลัมน์ขวาสุดของทุกแถว สามารถคลิกเพื่อดาวน์โหลด PDF ใบงานเคลม/ประวัติเครื่องชิ้นนั้นได้ทันทีในคลิกเดียว
- **แสดงราคาจัดซื้อ:** แสดงตัวเลขมูลค่าจัดซื้อของอุปกรณ์ เช่น `฿18,000`
- **ระบบแบ่งหน้า (Pagination):** แสดงผลหน้าละ 50 รายการ พร้อมปุ่ม `[ย้อนกลับ]` และ `[ถัดไป]` พร้อมระบุ *"แสดง X - Y จาก Z รายการ"*

## 2. ป้ายแสดงสถานะครุภัณฑ์ (Asset Status & Salvage Badges)

ระบบมีระบบป้ายสีมาตรฐานเพื่อจำแนกสภาพความพร้อมใช้งานของอุปกรณ์อย่างชัดเจน:

| สถานะ | ป้ายสีที่แสดง | ความหมาย |
|---|---|---|
| `Working` | `<span class="badge badge-working">🟢 ปกติ (Working)</span>` | เครื่องพร้อมใช้งานตามปกติในวอร์ด/แผนก |
| `Broken` | `<span class="badge badge-broken">🔴 ชำรุด/หมดประกัน (Danger)</span>` | เครื่องมีอาการเสียหรือหมดประกันรอซ่อม |
| `Pending Pickup` | `<span class="badge badge-vendor">🟡 รอศูนย์เข้ามารับ</span>` | รอตัวแทนศูนย์บริการมารับเครื่องไปซ่อม |
| `Pending Sell` | `<span class="badge badge-sell">💰 รอขายทอดตลาด</span>` | เครื่อง EOL รอดำเนินการขายทอดตลาด |
| `Sold` | `<span class="badge badge-sell">💰 ขายทอดตลาดแล้ว</span>` | จำหน่ายออกจากระบบผ่านการประมูล/ขาย |
| `Pending Donation` | `<span class="badge badge-donation">🎁 รอดำเนินการบริจาค</span>` | เครื่อง EOL รอดำเนินการบริจาคเพื่อการกุศล |
| `Donated` | `<span class="badge badge-donation">🎁 บริจาคเรียบร้อย</span>` | ส่งมอบให้หน่วยงานรับบริจาคเรียบร้อยแล้ว |
| `Scrapped` | `<span class="badge badge-scrapped">🗑️ แทงจำหน่าย (Scrapped)</span>` | ซากอุปกรณ์ที่แทงจำหน่ายทิ้ง |

## 3. การเพิ่มครุภัณฑ์ใหม่เข้าสู่ระบบ (Add New Asset)

### วิธีการเปิดฟอร์ม:
- คลิกปุ่ม **[เพิ่มครุภัณฑ์ใหม่ (Add New Asset)]** เหนือตารางคลังครุภัณฑ์ หรือ
- ใช้หัวอ่านสแกนบาร์โค้ดของเครื่องใหม่ที่ยังไม่มีในระบบ (หากล็อกอินด้วยสิทธิ์ Admin หน้าต่าง Modal จะเปิดขึ้นมาให้ทันที พร้อมใส่รหัส Tag ให้อัตโนมัติ)

### ข้อมูลที่ต้องระบุในแบบฟอร์ม:

| ฟิลด์ข้อมูล | ตัวอย่างค่า | บังคับ | คำอธิบาย |
|---|---|---|---|
| **รหัสครุภัณฑ์ (Asset Tag)** | `CIT-2026-MON-05` | ใช่ | รหัสเฉพาะห้ามซ้ำกันในระบบ |
| **ชื่ออุปกรณ์ (Device Name)** | `Dell UltraSharp 24"` | ใช่ | ชื่อเรียกอุปกรณ์ที่เข้าใจง่าย |
| **หมวดหมู่ (Category)** | `Computer` / `Monitor` / `Tablet` / `Scanner` / `Printer` / `Network` | ใช่ | ใช้คำนวณอายุและค่าเสื่อมราคา |
| **ยี่ห้อ (Brand)** | `Dell`, `HP`, `Apple`, `Zebra` | ใช่ | ดึงรายการจาก System Config |
| **รุ่น (Model)** | `OptiPlex 7090 Micro` | ใช่ | ชื่อรุ่นย่อย |
| **หมายเลขซีเรียล (Serial Number)** | `SN-99887766` | ใช่ | หมายเลขเฉพาะตัวเครื่องจากโรงงาน |
| **สถานที่ติดตั้ง (Location)** | `Ward 20`, `ER Triage` | ใช่ | วอร์ดหรือแผนกที่ติดตั้งอุปกรณ์ |
| **วันเริ่มรับประกัน (Warranty Start)** | `2026-01-01` | ใช่ | วันที่เริ่มต้นนับประกันตามใบเสร็จ |
| **ระยะเวลารับประกัน (Warranty Months)** | `12`, `24`, `36`, `60` เดือน | ใช่ | ระบบจะคำนวณ `warranty_end` ให้อัตโนมัติ |
| **ราคาจัดซื้อ (Purchase Price)** | `24500` | ไม่ | มูลค่าจัดซื้อ (ใช้คำนวณ Viability Score) |
| **ต้องล้างข้อมูล (PDPA Storage)** | ☑️ เช็คถูก | ไม่ | หากเครื่องมี HDD/SSD ต้องเลือกตัวเลือกนี้ |
| **PO Number / Invoice No.** | `PO-69-0012` | ไม่ | เลขที่ใบสั่งซื้อ/ใบกำกับภาษี |

### กลไกป้องกันข้อมูลซ้ำแบบเรียลไทม์ (Live Anti-Duplicate Safeguard):
- เมื่อพิมพ์ `Asset Tag` หรือ `Serial Number` ระบบจะตรวจสอบกับฐานข้อมูลทันที
- หากตรวจพบว่าซ้ำ ระบบจะแสดงแถบสีแดงเตือนและปิดปุ่มบันทึก เพื่อป้องกันการลงทะเบียนซ้ำซ้อน

### การส่งอีเมลแจ้งเตือนอัตโนมัติ (Automated Email Notification):
- ทันทีที่เพิ่มครุภัณฑ์ใหม่สำเร็จ เซิร์ฟเวอร์จะส่งอีเมลแจ้งเตือนผ่านเทมเพลต `ASSET_ADDED` ไปยังผู้ดูแลระบบที่ระบุใน `NOTIFY_EMAIL` หรือ `admin@claimit.local` โดยอัตโนมัติ

## 4. สรุป REST API สำหรับงานครุภัณฑ์

| Method | Endpoint | สิทธิ์ | คำอธิบาย |
|---|---|---|---|
| `GET` | `/api/assets` | Staff+ | ดึงรายการครุภัณฑ์ (รองรับ `page`, `limit`, `status`) |
| `GET` | `/api/assets/:tag` | Staff+ | ดึงข้อมูลครุภัณฑ์เดี่ยว (ผูกข้อมูลเคลมล่าสุด) |
| `GET` | `/api/assets/:tag/evaluate` | Staff+ | คำนวณ Viability Score และผลประเมินความคุ้มค่า |
| `GET` | `/api/assets/:tag/pdf` | Staff+ | สร้างและดาวน์โหลดรายงาน PDF ทางการ |
| `POST` | `/api/assets` | Admin | ลงทะเบียนครุภัณฑ์ใหม่ (ตรวจสอบรหัสซ้ำ + ส่งอีเมล) |
| `PUT` | `/api/assets/:tag` | Admin | แก้ไขรายละเอียดข้อมูลครุภัณฑ์ |
| `DELETE` | `/api/assets/:tag` | Admin | ทำการ Soft Delete ครุภัณฑ์ (`is_deleted = 1`) |
| `POST` | `/api/assets/update-status` | Staff+ | เปลี่ยนสถานะ (เช่น Working $\rightarrow$ Broken) |
| `POST` | `/api/assets/sanitize` | Staff+ | ยืนยันการล้างข้อมูล PDPA ด้วยรหัส Wipe Code |
| `POST` | `/api/assets/claim` | Staff+ | ส่งเคลมศูนย์บริการ (มีระบบตรวจสอบ PDPA Gate) |
| `POST` | `/api/assets/resolve-claim` | Staff+ | บันทึกรับเครื่องคืนจากการซ่อม (Return to Stock) |
| `POST` | `/api/assets/salvage` | Staff+ | จัดการซากอุปกรณ์ EOL (ขาย/บริจาค/แทงจำหน่าย) |

## 5. การคัดลอกข้อมูลด่วน (Copy TSV to Clipboard)

คลิกปุ่ม **[คัดลอกข้อมูล (TSV)]** เหนือตารางคลังครุภัณฑ์:
- ระบบจะแปลงข้อมูลครุภัณฑ์ทั้งหมดในตารางปัจจุบันให้อยู่ในรูป Tab-Separated Values
- คัดลอกลงใน Clipboard ของเครื่องโดยตรง
- ผู้ใช้สามารถเปิด Microsoft Excel, Google Sheets, หรือ Notepad แล้วกด `Ctrl + V` เพื่อวางตารางข้อมูลได้ทันที
