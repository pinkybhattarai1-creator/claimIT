# 13 — บันทึกประวัติการเคลื่อนย้ายและความปลอดภัย (Audit Trail)

> **กลุ่มผู้ใช้:** IT Staff / IT Administrator | **เวลาอ่าน:** ~5 นาที

---

## Audit Trail คืออะไร?

**Audit Trail** คือระบบบันทึกประวัติความปลอดภัยและการเคลื่อนย้ายทางกายภาพของทรัพย์สินทั้งหมดใน ClaimIT (`routes/audit.js` และ `public/js/audit.js`) ถูกสร้างขึ้นเพื่อให้สอดคล้องกับมาตรฐาน **ISO/IEC 27001**, มาตรการคุ้มครองข้อมูลส่วนบุคคล **PDPA**, และเกณฑ์การตรวจสอบของฝ่ายควบคุมคุณภาพโรงพยาบาล (HA / JCI)

---

## คุณสมบัติสำคัญ: ไม่สามารถแก้ไขหรือลบได้ (Immutable Audit)

- **ไม่มีคำสั่ง DELETE / UPDATE:** ระบบไม่มี API สำหรับแก้ไขหรือลบบันทึกประวัติย้อนหลัง
- **บันทึกอัตโนมัติจากเซิร์ฟเวอร์:** ทุกเหตุการณ์จะถูกบันทึกผ่านฟังก์ชัน `recordAuditLog()` จากฝั่งเซิร์ฟเวอร์โดยตรง
- **รหัสติดตามรับประกันความไม่ซ้ำกัน (Guaranteed Unique Log Code):** แต่ละรายการจะมีรหัสอ้างอิง เช่น:
  ```text
  CHG-20260827-3F9A1B
  ```
  (สร้างจากวันที่ปัจจุบันและตัวเลขสุ่มระดับ Cryptographic Hexadecimal)

---

## โครงสร้างข้อมูลในตาราง Audit Trail

| คอลัมน์ | รายละเอียดข้อมูล |
|---|---|
| **รหัสติดตาม (Log Code)** | รหัสอ้างอิงเฉพาะตัว (คลิกเพื่อคัดลอกลง Clipboard ได้ทันที) |
| **วัน-เวลาบันทึก (Timestamp)** | วันและเวลาที่เกิดเหตุการณ์อย่างแม่นยำ |
| **รหัสครุภัณฑ์ (Asset Tag)** | รหัสเครื่องที่เกี่ยวข้อง หรือ `SYSTEM_AUTH` สำหรับเหตุการณ์ล็อกอิน |
| **จุดติดตั้ง / ศูนย์เคลม** | แผนก, วอร์ด, หรือชื่อ Vendor ปลายทาง |
| **สถานะครุภัณฑ์** | `Working`, `Broken`, `Pending Pickup`, `Sanitized`, ฯลฯ |
| **ทิศทางการเคลื่อนย้าย** | `IN` (นำเข้า/คืนคลัง), `OUT` (ส่งออก/ตัดจำหน่าย), `STATE_CHANGE` (เปลี่ยนสถานะใบเคลม), หรือ `AUTH` (เหตุการณ์ล็อกอิน/ความปลอดภัย) |
| **ผู้บันทึกรายการ (Actor)** | ชื่อ Username ของเจ้าหน้าที่ผู้ดำเนินการ |
| **รายละเอียด (Details)** | คำอธิบายเหตุการณ์ เช่น ข้อความแจ้งซ่อม, รหัส Wipe Code, ผลการเคลม |

## การค้นหาและตัวกรองข้อมูลขั้นสูง (Audit Toolbar Controls)

### 1. ปุ่มช่วงเวลาด่วน (Time-Span Presets):
คลิกปุ่มเพื่อเลือกช่วงเวลาที่ต้องการดูข้อมูลใน 1 คลิก:
- `[ทั้งหมด (All)]` — ดึงประวัติทั้งหมด
- `[วันนี้ (Today)]` — ดูเฉพาะกิจกรรมที่เกิดขึ้นในวันนี้
- `[เมื่อวาน (Yesterday)]` — กิจกรรมของเมื่อวาน
- `[ย้อนหลัง 7 วัน]` — กิจกรรมในสัปดาห์ปัจจุบัน
- `[ย้อนหลัง 30 วัน]` — ประวัติประจำเดือน

### 2. กรองตามช่วงวันที่กำหนดเอง (Custom Date Range):
- ระบุวันที่เริ่มต้นในช่อง *"จาก"* และวันที่สิ้นสุดในช่อง *"ถึง"*
- คลิกปุ่ม `[กรองตามช่วงวันที่]`

### 3. ค้นหาแบบเรียลไทม์ (Live Debounced Search):
- พิมพ์คำค้นหาในช่องค้นหา (มีระบบหน่วงเวลา 300ms เพื่อประหยัดทรัพยากรเซิร์ฟเวอร์)
- ค้นหาได้จาก: รหัสติดตาม, รหัสครุภัณฑ์, ชื่อผู้ใช้งาน, ชื่อแผนก หรือข้อความในรายละเอียด

## ตัวชี้วัดปริมาณงานประจำวัน (Daily Case Volume Metrics)

ที่ส่วนหัวของตาราง Audit Trail จะมีแถบสรุปข้อมูลกิจกรรมประจำวัน (`loadAuditSummary()`):
- **Volume Badge:**
  - `🟢 ปกติ (0–9 รายการ/วัน):` แสดงป้ายสีเขียว เช่น *5 รายการวันนี้*
  - `⚡ หนาแน่นพิเศษ (10+ รายการ/วัน):` แสดงป้ายสีแดง เช่น *18 รายการวันนี้*
- **สถิติ 30 วันล่าสุด:** แสดงวันที่มีการบันทึกกิจกรรมสูงสุด (Peak Activity Day) เช่น *"วันที่มีกิจกรรมสูงสุดคือ 2026-08-25 (24 รายการ)"*

---

## ฟังก์ชันอำนวยความสะดวก: คลิกเพื่อคัดลอกรหัสติดตาม (Click-to-Copy)

ที่คอลัมน์รหัสติดตามในตาราง:
- เมื่อคลิกที่รหัส `CHG-YYYYMMDD-XXXXXX`
- ระบบจะเรียก `window.copyTrackingCode()` คัดลอกรหัสเข้าสู่ Clipboard ของเครื่องทันที
- แสดง Toast ยืนยัน: `✅ คัดลอกรหัสติดตาม CHG-XXXX สำเร็จแล้ว!`
- สะดวกในการนำรหัสไปส่งต่อในไลน์หรือเขียนลงใบงาน

---

## การส่งออกรายงานประวัติความปลอดภัย (Audit Export)

- คลิกปุ่ม **[ส่งออก Excel ทั้งหมด (.xls)]** ในหน้า IT Portal หรือ Quick Sidebar
- ระบบจะดาวน์โหลดไฟล์ Multi-Sheet Excel ที่มีแผ่นงาน **"บันทึกการเปลี่ยนแปลง (Audit)"** บรรจุประวัติย้อนหลังสูงสุด 2,000 รายการล่าสุด เหมาะสำหรับเสนอต่อคณะกรรมการตรวจสอบ HA / JCI
