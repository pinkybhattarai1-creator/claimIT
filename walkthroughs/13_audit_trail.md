# 13 — Audit Trail (บันทึกประวัติการเคลื่อนย้าย)

กลุ่มผู้ใช้: IT Staff / Admin

---

## Audit Trail คืออะไร?

บันทึกถาวรของทุกเหตุการณ์ในระบบ:
- การเคลื่อนย้ายครุภัณฑ์ (IN / OUT / STATE_CHANGE)
- การเปลี่ยนสถานะ
- การล็อกอิน
- การสร้าง/แก้ไขใบเคลม

ทุกรายการมี "รหัสติดตามเฉพาะตัว (log_code)" ไม่ซ้ำกัน

---

## ตาราง Audit Trail

แสดงในหน้า IT Portal ส่วนล่างสุด:

| คอลัมน์ | คำอธิบาย |
|---|---|
| รหัสติดตาม (Code) | เช่น CHG-2026-001 |
| วัน-เวลาบันทึก | Timestamp แม่นยำ |
| รหัสครุภัณฑ์ | Asset Tag |
| จุดติดตั้ง/ศูนย์เคลม | Department / Vendor |
| สถานะครุภัณฑ์ | Working / Broken / ฯลฯ |
| การเคลื่อนย้าย | IN / OUT / STATE_CHANGE |
| ผู้บันทึกรายการ | Username ผู้ดำเนินการ |
| รายละเอียด | คำอธิบายเพิ่มเติม |

---

## ตัวกรองข้อมูล (Filters)

### กรองตาม Time Span:
- ทั้งหมด (All)
- วันนี้ (Today)
- เมื่อวาน (Yesterday)
- ย้อนหลัง 7 วัน
- ย้อนหลัง 30 วัน

### กรองตามช่วงวันที่:
- เลือก "จาก" และ "ถึง"
- กดปุ่ม [กรอง]

### ค้นหาด้วย Keyword:
- ค้นหาได้จาก: Asset Tag, Log Code, Username, Department, รายละเอียด

---

## สถิติประจำวัน (Daily Case Volume)

แถบบนตาราง Audit Trail แสดง:
- จำนวนกิจกรรมวันนี้
- วันที่มีกิจกรรมสูงสุด (Peak Day)
- Badge สีเขียว/เหลือง/แดง ตามปริมาณ

เกณฑ์:
- 0–9 รายการ/วัน: Normal (สีเขียว)
- 10+ รายการ/วัน: Busy (สีเหลือง/แดง)

---

## ส่งออก Audit Log

กดปุ่ม [ส่งออกบันทึกเป็น Excel/CSV] → ดาวน์โหลดไฟล์

API:
GET /api/export/csv/audit-logs

---

## API สำหรับ Audit

| Endpoint | คำอธิบาย |
|---|---|
| GET /api/audit-logs | ดู log พร้อม filter |
| GET /api/audit-summary | สถิติรายวัน 30 วันล่าสุด |

---

## กฎสำคัญ: Immutable Audit

- ลบรายการ Audit ไม่ได้ (ไม่มี DELETE API)
- แก้ไขย้อนหลังไม่ได้
- ทุก action ถูก log อัตโนมัติโดย Backend
